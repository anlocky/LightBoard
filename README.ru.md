# LightBoard

Лёгкая и приватная клавиатура для Android. Два дизайна (Material и Cupertino в стиле iOS), свайп-ввод, умные подсказки по словарям, которые вы собираете сами, зашифрованная история буфера обмена и небольшое быстрое ядро, бережное к батарее.

- **Нет разрешения на интернет.** Ни аналитики, ни рекламы, ни слежки.
- **Данные на устройстве зашифрованы.** История буфера и запомненные слова защищены ключом из хранилища ключей Android (Keystore).
- **Мало ресурсов.** Одно нарисованное вручную представление вместо дерева view, компактные словари, фоновая работа только по необходимости.
- **Открытый код**, лицензия Apache 2.0.

## Возможности

**Набор текста**
- Свайп-ввод с линией следа, всплывающие подсказки клавиш и символы на клавишах
- Подсказки слов, предсказание следующего слова и автоисправление по словарям, собранным на вашем устройстве
- 26 раскладок (латиница, кириллица, греческий, иврит, арабский, персидский); многоязычный ввод следует списку языков системы
- Цифровые панели для телефона, чисел, PIN и даты; отдельная планшетная раскладка со стрелками
- Заглавные автоматически, точка автоматически, пробел после `.` и `,`, умное тире
- Калькулятор: наберите `2+2*3=` и получите результат прямо в тексте
- Курсор свайпом по пробелу, жест «стереть всё», кнопка «Отменить» для стёртого или вставленного текста
- Режим инкогнито: ничего не запоминается и не сохраняется
- Голосовой ввод и панель эмодзи с недавними

**Оформление**
- Дизайны Material и Cupertino, светлая, тёмная и автоматическая темы, цветовые схемы Material
- Размытие подложки (Cupertino, Android 12+), высота клавиш, скругление, размер шрифта
- Нижняя панель с глобусом и микрофоном, отдельная клавиша языка, перестановка значков
- Режим одной руки и разделённая клавиатура
- Настройки отдельных приложений для самых важных параметров

**Буфер обмена и быстрые действия**
- История буфера со сроком хранения, закреплёнными записями и очисткой в одно касание
- Строки, похожие на пароли, одноразовые коды, токены и фразы восстановления, отфильтровываются и в историю не попадают (фильтр эвристический, гарантии нет)
- Коды из СМС в строке подсказок (читается только код, ничего не сохраняется)
- Недавний скриншот в строке подсказок для полей с поддержкой изображений
- Подсказки автозаполнения на поддерживаемых версиях Android

**Резервные копии**
- Экспорт и импорт настроек, запомненных слов и истории буфера
- Всё личное (запомненные слова, буфер) всегда шифруется вашим паролем: AES-256-GCM, PBKDF2-HMAC-SHA256, 600 000 итераций

**Языки интерфейса:** Русский, English, Українська, Deutsch, Español, Português, Français, Italiano, Türkçe, Polski, Bahasa Indonesia, Tiếng Việt.

## Конфиденциальность и безопасность

- В манифесте нет разрешения `INTERNET`, резервное копирование Android (`allowBackup`) отключено.
- Запомненные слова, пары слов и история буфера хранятся в файлах, зашифрованных AES-256-GCM; ключ не покидает Android Keystore.
- В полях паролей, e-mail, адресов и имён, в полях с запретом персонального обучения и в режиме инкогнито ничего не запоминается.
- Разрешения запрашиваются только при включении нужной функции: микрофон (голосовой ввод), СМС (коды), фото (недавние скриншоты).
- Голосовой ввод использует службу речи вашего устройства. Если там выбран сетевой распознаватель, звук получает его поставщик по своим правилам; у самого LightBoard доступа в интернет нет.
- Подробнее: [`PRIVACY.txt`](PRIVACY.txt), [`SECURITY.md`](SECURITY.md).

## Словари

Собирайте словари в приложении из частотных списков (одна строка: `слово число`): *Настройки → Словари → Импорт словаря из файла*. Язык определяется по имени файла (например `ru_50k.txt`) или по самим словам. После импорта исходный файл можно удалить: приложение хранит собственную компактную копию; кнопка *Удалить словари* убирает и её. Лицензии источников перечислены в [`NOTICE`](NOTICE).

## Сборка

```
gradle assembleRelease
```

Для подписи релиза создайте `keystore.properties` (файл не попадает в репозиторий). Без него сборка подписывается отладочным ключом и выводит предупреждение; `-Plb.strictSigning=true` превращает предупреждение в ошибку. Тесты на компьютере: `gradle testDebugUnitTest`.

Требования: Android 6.0 (API 23) и новее. Приложение собирается и нацелено на Android 16 (API 36).
