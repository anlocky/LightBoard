# LightBoard

Лёгкая и приватная клавиатура для Android. Два дизайна (Material и Cupertino в стиле iOS), свайп-ввод, умные подсказки по словарям, которые вы собираете сами, зашифрованная история буфера обмена и небольшое быстрое ядро, бережное к батарее.

- **Нет разрешения на интернет.** Ни аналитики, ни рекламы, ни слежки.
- **Данные на устройстве зашифрованы.** История буфера и запомненные слова защищены ключом из хранилища ключей Android (Keystore).
- **Мало ресурсов.** Одно нарисованное вручную представление вместо дерева view, компактные словари, фоновая работа только по необходимости.
- **Открытый код**, лицензия Apache 2.0.

## Возможности

**Набор текста**
- Свайп-ввод с линией следа, всплывающие подсказки клавиш и символы на клавишах; декодер учитывает скорость пальца и пары слов, которые вы действительно используете
- Подсказки слов, предсказание следующего слова и автоисправление по словарям, собранным на вашем устройстве; автоисправление также ориентируется на слова, которым вы его научили
- 86 раскладок: 26 с готовыми раскладками (латиница, кириллица, греческий, иврит, арабский, персидский) и 60, собираемые по алфавиту языка (ещё языки на латинице и кириллице, армянский, грузинский, тайский, хинди, бенгальский, тамильский, телугу, малаялам, сингальский, урду); многоязычный ввод следует списку языков системы
- Цифровые панели для телефона, чисел, PIN и даты; отдельная планшетная раскладка со стрелками
- Заглавные автоматически, точка автоматически, пробел после `.` и `,`, умное тире
- Калькулятор: наберите `2+2*3=` и получите результат прямо в тексте
- Курсор свайпом по пробелу или (по умолчанию выключено, заменяет курсор) переключение языка свайпом по пробелу по горизонтали или по вертикали с настраиваемым расстоянием свайпа, жест «стереть всё», кнопка «Отменить» для стёртого или вставленного текста
- Режим инкогнито: ничего не запоминается и не сохраняется
- Голосовой ввод и панель эмодзи с недавними

**Оформление**
- Дизайны Material и Cupertino, светлая, тёмная и автоматическая темы, цветовые схемы Material
- Размытие подложки (Cupertino, Android 12+), высота клавиш, скругление, размер шрифта, жирный шрифт
- Ползунки цвета панели и клавиш Material
- Нижняя панель с глобусом и микрофоном, отдельная клавиша языка, перестановка значков
- Режим одной руки и разделённая клавиатура
- Настройки отдельных приложений для самых важных параметров

**Буфер обмена и быстрые действия**
- История буфера со сроком хранения, закреплёнными записями и очисткой в одно касание
- Строки, похожие на пароли, одноразовые коды, токены и фразы восстановления, отфильтровываются и в историю не попадают (фильтр эвристический, гарантии нет)
- Коды из СМС в строке подсказок (читается только код, ничего не сохраняется)
- Недавний скриншот в строке подсказок для полей с поддержкой изображений
- Подсказки автозаполнения на поддерживаемых версиях Android

**Резервные копии**
- Экспорт и импорт настроек, запомненных слов и истории буфера
- Всё личное (запомненные слова, буфер) всегда шифруется вашим паролем: AES-256-GCM, PBKDF2-HMAC-SHA256, 600 000 итераций
- Поля пароля скрыты по умолчанию, справа есть кнопка показа и скрытия

**Языки интерфейса:** Русский, English, Українська, Deutsch, Español, Português, Français, Italiano, Türkçe, Polski, Bahasa Indonesia, Tiếng Việt.

## Конфиденциальность и безопасность

- В манифесте нет разрешения `INTERNET`, резервное копирование Android (`allowBackup`) отключено.
- Запомненные слова, пары слов и история буфера хранятся в файлах, зашифрованных AES-256-GCM; ключ не покидает Android Keystore.
- В полях паролей, e-mail, адресов и имён, в полях с запретом персонального обучения и в режиме инкогнито ничего не запоминается и история буфера не пишется.
- Разрешения запрашиваются только при включении нужной функции: микрофон (голосовой ввод), СМС (коды), фото (недавние скриншоты).
- Голосовой ввод использует службу речи вашего устройства. Если там выбран сетевой распознаватель, звук получает его поставщик по своим правилам; у самого LightBoard доступа в интернет нет.
- Подробнее: [`PRIVACY.txt`](PRIVACY.txt), [`SECURITY.md`](SECURITY.md).

## Словари

Словари собираются на вашем устройстве из частотных списков (одна строка: `слово число`) в *Настройки → Словари*:

1. **Загрузить словарь** открывает исходный список в вашем браузере (у самого LightBoard нет доступа в сеть).
2. **Импортировать словарь** собирает компактный словарь из сохранённого файла.

Язык определяется по имени файла (например `ru_50k.txt`) или по самим словам. Списки с числами сортируются по частоте, принимаются файлы до 96 МБ. После импорта исходный файл можно удалить: приложение хранит собственную компактную копию; у каждого импортированного словаря есть кнопка *Удалить* с подтверждением. Лицензии источников перечислены в [`NOTICE`](NOTICE).

## Что нового в 1.1.0

- **Словари:** двухшаговые загрузка и импорт, отдельное удаление каждого словаря, импорт с учётом частот, ограничение размера файла.
- **Свайп-ввод:** точнее (реальное время движения пальца, контекст пар слов, клавиши любого письма), декодирование вне главного потока, исправлены «залипание» жеста и пропадавшие правые буквы при включённом ряде цифр.
- **Подсказки и автоисправление** используют слова и пары слов, которые вы запомнили.
- **Один движок для двух дизайнов:** Material и Cupertino ведут себя одинаково и отличаются только видом и раскладкой.
- **Резервные копии:** кнопка показа и скрытия пароля, файлы читаются в фоне.
- **Буфер обмена:** история не пишется в полях с запретом персонального обучения.
- **Язык свайпом по пробелу:** настраиваемое расстояние срабатывания.
- **Android 16:** приложение собирается и нацелено на API 36.

## Сборка

```
gradle assembleRelease
```

Для подписи релиза создайте `keystore.properties` (файл не попадает в репозиторий). Без него сборка подписывается отладочным ключом и выводит предупреждение; `-Plb.strictSigning=true` превращает предупреждение в ошибку. Тесты на компьютере: `gradle testDebugUnitTest`.

Требования: Android 6.0 (API 23) и новее. Сборка: Android Gradle Plugin 8.13, Gradle 8.13 и JDK 17; приложение собирается и нацелено на Android 16 (API 36).
