# Безопасность / Security

Сообщения об уязвимостях отправляйте через приватное сообщение об уязвимостях на странице репозитория (Security → Report a vulnerability), не создавая публичный issue. / Please report vulnerabilities privately through the repository's "Report a vulnerability" feature instead of opening a public issue.

Приложение не использует интернет и не собирает данные; особенно важны сообщения о возможности утечки вводимого текста, истории буфера, кодов из СМС и резервных копий. / The app uses no network and collects no data; reports about possible leaks of typed text, clipboard history, SMS codes or backups are especially valuable.
